# Privacy

PW Focus does not collect, transmit, sell, or share user data. It has no analytics, advertising, telemetry, remote code, or external network service.

## Data stored by the browser

PW Focus uses the browser's synchronized extension storage for:

- Whether Focus mode and Always expanded are enabled.
- Appearance preferences.
- Dashboard and Batch Offerings order.
- CSS selectors and short text labels for elements the user chooses to hide.

Hidden-element labels can contain text visible on the selected PW page. This data is used only to find the same element after PW rerenders its interface. Chrome or Firefox may synchronize these settings through the user's signed-in browser account according to that browser's sync settings.

PW Focus does not read or store cookies, passwords, authentication tokens, browsing history, payment information, or PW account credentials.

## Page access

The extension runs only on `https://www.pw.live/study-v2/*`. It reads the rendered page structure solely to apply the user's layout, ordering, expansion, and hiding preferences.

## Removing stored data

Use **Restore manually hidden items** and **Reset dashboard order** in the extension menu. Disabling or uninstalling PW Focus stops all page changes. The browser can remove the extension's saved settings when PW Focus is uninstalled.
